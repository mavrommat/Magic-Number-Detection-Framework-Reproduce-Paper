# Reproducing the Paper

## Requirements

A dedicated Python virtual environment named `magic_venv` is recommended to ensure that the required dependencies are isolated from the system Python installation.

### macOS and Linux

Create and activate the virtual environment:

```bash
python3 -m venv magic_venv
source magic_venv/bin/activate
```

Then install the required dependencies:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Windows

Using **Command Prompt (CMD)**:

```cmd
python -m venv magic_venv
magic_venv\Scripts\activate
```

Using **PowerShell**:

```powershell
python -m venv magic_venv
.\magic_venv\Scripts\Activate.ps1
```

Then install the required dependencies:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

After activation, the terminal should display `(magic_venv)` before the command prompt, indicating that the virtual environment is active.

> **Warning:** Reproducing the complete paper may take several hours, depending on the available hardware.

## Analysis Structure

The paper consists of two independent analysis pipelines:

* **Synthetic Analysis** — evaluates the algorithm using synthetic datasets with known injected Magic Numbers.

* **Real-World Analysis** — applies the algorithm to real-world datasets and investigates the detected Magic Numbers.

The files and generated results for each pipeline are organised in their respective directories:

```text
Synthetic Experiments/

Real_World_Analysis/
```

Each pipeline consists of dependent stages and should be executed as a complete chain.

## Running the Analysis

The reproduction workflow is controlled through:

```text
Reproduce_Paper.py
```

At the beginning of the script, select which analysis pipeline to run:

```python
RUN_SYNTHETIC_ANALYSIS = True
RUN_REAL_WORLD_ANALYSIS = True
```

Set a pipeline to `True` to run it or `False` to skip it.

Then, with `magic_venv` activated, run:

```bash
python Reproduce_Paper.py
```

The script automatically executes the stages of each enabled pipeline in the correct order.

### Synthetic Analysis

The synthetic pipeline performs the grid searches, evaluates detection performance, and subsequently carries out the statistical analysis and scalability benchmarking.

Its generated files are stored in:

```text
Synthetic Experiments/
```

### Real-World Analysis

The real-world pipeline performs the detection analysis, processes the generated results, creates plots, and performs hyperparameter sensitivity and Magic Number pattern analyses.

Its generated files are stored in:

```text
Real_World_Analysis/
```

> **Note:** Some stages within each pipeline use files generated by earlier stages. The complete pipeline therefore runs the analyses in the appropriate order to ensure that all required intermediate results are available.
